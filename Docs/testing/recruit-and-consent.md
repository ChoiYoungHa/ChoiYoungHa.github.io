# 외부 테스터 모집·동의·기록 문안

## 모집 과제 한 문장

> URL을 열고 거대 수목까지 찾아가 보세요.

이 프로젝트를 처음 보는 3~5명에게 위 문장만 전달한다. 조작법·방향·기술 설명이나 사전 화면은 보여주지 않는다.

## 익명 기록 동의문

> 이름·연락처·계정·IP·화면 녹화는 수집하지 않고, 익명 ID와 실행 환경·첫 이동 시간·도달 여부·도움 횟수·한 문장 감상만 기록하려 합니다. 익명 기록에 동의하시나요?

동의가 `yes`일 때만 세션을 시작한다. `no`이면 어떤 세션 값도 저장하지 않으며, 익명 ID `T-YYYYMMDD-NN`과 실제 사람의 대응표를 만들지 않는다.

## 세션 기록 절차

기록자는 [`sessions-template.csv`](sessions-template.csv)를 날짜별 `sessions-YYYYMMDD.csv`로 복사하고 한 사람당 한 행을 쓴다. 열 순서는 다음 18개로 고정한다.

| 시점 | 열 | 기록값 |
|---|---|---|
| 시작 전 | `tester_id` | `T-YYYYMMDD-NN` 익명 ID |
| 시작 전 | `date` | KST 세션 날짜 `YYYY-MM-DD` |
| 시작 전 | `consent` | 위 동의에 대한 `yes`; `no`면 기록 중단 |
| 화면 표시 직후 | `os` | OS 이름과 주 버전 |
| 화면 표시 직후 | `browser` | 브라우저 이름 |
| 화면 표시 직후 | `browser_version` | 브라우저 주 버전 이상 |
| 화면 표시 직후 | `gpu_string` | 페이지 HUD의 adapter·ANGLE 문자열 그대로 |
| 화면 표시 직후 | `backend` | HUD의 `WebGPU` 또는 `WebGL2` |
| 화면 표시 직후 | `preset` | 실행한 `low` 또는 `base` |
| 화면 표시 직후 | `launched` | 링크가 열리고 화면이 표시되면 `yes`, 아니면 `no` |
| 첫 입력 순간 | `ttfi_sec` | URL을 연 시점부터 첫 이동까지 초; 미실행은 `-` |
| 종료 시 | `reached_target` | 거대 수목 도달 `yes`/`no` |
| 종료 시 | `time_to_target_sec` | 시작부터 도달까지 초; 미도달은 `-` |
| 세션 내내 | `help_count` | 조작·방향을 알려준 횟수, 0 이상 정수 |
| 종료 시 | `dropoff_point` | 포기·이탈 위치, 없으면 `-` |
| 종료 직후 | `recall_one_line` | “어땠어요?”에 대한 유도 없는 한 문장 |
| 첫 5초 | `wow_5sec` | 목표 지향 발화가 나오면 `yes`, 아니면 `no` |
| 종료 시 | `notes` | 짧은 보충, 없으면 `-`; 개인정보 금지 |

기록자는 과제 수행 중 방향이나 조작을 알려주지 않는다. 테스터가 요청해 도움을 줬다면 매번 `help_count`를 1 올리고, 해당 세션의 도달은 자력 도달로 세지 않는다.

## 판정 규칙

유효 표본은 동의한 처음 보는 사람 최소 3명이다. 3명 기준 합격선은 다음과 같다.

| 지표 | 합격선 |
|---|---|
| `launched` | **3/3 yes** |
| `ttfi_sec` | 유효 3명의 중앙값 **≤3초** |
| `reached_target` + `help_count=0` | 자력 도달 **2명 이상** |

`wow_5sec` 과반 yes는 정성 보조 지표이며 위 세 조건의 실패를 뒤집지 않는다. 3명 미만은 표본 부족이고, 결과를 백분율로 확대 해석하지 않는다.
