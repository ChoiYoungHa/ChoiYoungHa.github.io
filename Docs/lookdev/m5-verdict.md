## 2. 자산 밀도 3지표

| 지표 | 목표 | 실측 | 판정 | 비고 |
|---|---|---|---|---|
| 화면 내 텍스처 수 | ≥6 | `measure.mjs`: 미지원(null) / 프로브 실측 `renderer.info.memory.textures` S1 **14**, bench peak 15, 재질 map 고유 3(bark·grass 아틀라스·집) | 조건부 PASS | `Docs/qa/m5-pipelines-s1.json`. info.textures는 그림자맵·환경맵 포함 |
| 메시 종류 수 | ≥8 | **16** | PASS | scene-tris inputs 고유 지오메트리(R96 json 기준) |
| 수목 실루엣 경계 픽셀 비율 | M3 0.0916 ×2 = ≥0.183 | **0.0351**(경계 1,174 / 마스크 33,429px, ROI 553,89~739,302) | FAIL | 아래 부적합 사유 |

**실루엣 지표 부적합 사유**: 지표 = ROI 안 수목 마스크의 경계 픽셀 ÷ 마스크 면적. M3 절차 수목은 잎 카드가 성기게 흩어져 경계가 많았고(0.0916), Big Tree GLB는 잎이 수관 덩어리로 뭉쳐 **면적은 커지고 경계는 줄어** 비율이 떨어진다. 즉 이 비율은 "디테일"이 아니라 "성김"을 재며, 목표 이미지의 수목(빽빽한 수관)도 이 지표로는 낮게 나온다. 대체 제안: ROI를 수관 bbox로 잡고 (a) 잎 알파 컷 경계의 고주파 에너지(라플라시안 합/면적) 또는 (b) 실루엣 볼록 껍질 대비 요철 비율(concavity)을 쓰는 것 — 지표 재정의는 계획서 §10 정정 사항이라 master·영하님 결정.
