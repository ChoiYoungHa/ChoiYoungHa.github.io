# vista-mid pitch 후보 계산 (R52-A, 2026-08-26)

> **계산만 기록한다. `vistas.json` 에는 넣지 않았다**(기본 동작 불변). 채택은 master.
> 적용 방법: `src/data/vistas.json` marker 에 선택 필드 `pitchDeg`(도, + = 올려봄) → `VistaCamera` 가 `lookAt(target)` 뒤 카메라 로컬 X 축으로 그만큼 더 회전(`camera.rotateX`). 부재·0 = 기존 그대로.

## 1. 입력값 (전부 코드·데이터 실측, Node)

| 항목 | 값 | 출처 |
|---|---|---|
| vista-mid 위치 | (18, −60), 지면 −1.430 m → 눈높이 y **0.170** | `vistas.json` + `sampleHeight` |
| heroTree 중심 | (38, −96), 지면 **0.194** | `placement.json` + `sampleHeight` |
| 수평 거리 | **41.18 m** | √(20²+36²) |
| 수목 높이 | 48 m 스펙, 실제 지오메트리 maxY **46.85 m**(LOD0) | `heroTreeGeometry.ts` `HERO_TREE.height`·`buildHeroTree(0).bounds` |
| 수관 중심 | 지면 + 38.4 m (H·0.80) | `heroTreeGeometry.ts` L289 |
| 카메라 vFOV | 55° → 반각 **27.5°** | `FollowCamera.tsx` `CAMERA.fov` |
| 현재 lookAt 시선 고도 | **+2.26°**(target = 수목 지면 + 1.6 m) | `App.tsx` VistaCamera |

※ 스펙 문구의 "수관 127 m" 는 수목 높이가 아니다. 수목은 48 m 이고, 127 m 는 spawn(0,24)→heroTree 거리(125.9 m)에 가깝다(`FollowCamera.tsx` 주석의 127 m 도 같은 뜻으로 보인다). 계산은 실제 지오메트리 46.85 m 로 했다.

## 2. 현재 상태(pitch 0)가 왜 잘리는가

- 프레임 상단 고도 = 2.26 + 27.5 = **29.76°** → 41.18 m 거리에서 지면 위 **23.5 m** 까지만 보인다.
- 수관 하단(≈ +37.8°)·수관 중심(+43.0°)·수관 꼭대기(+48.7°)가 전부 프레임 밖 → M2-29 "수관 상단 잘림"(줄기만 보임)의 수치 근거. 현재 vista-mid 는 L4 실루엣 판정에 부적합.

## 3. 후보 (pitchDeg = 절대 고도 − 2.26°)

| 후보 | 의도 | 카메라 절대 고도 | **pitchDeg** | 프레임 안 | 비고 |
|---|---|---|---|---|---|
| A | 수관 꼭대기를 프레임 상단 모서리에 | 21.20° | **+18.9** | 지면 −6.3°~꼭대기 48.7° | 여유 0 — 흔들리면 꼭대기 잘림 |
| A′ | A + fov 5% 여유 | 23.95° | **+21.7** | 지면 −3.6°~ 51.5° | 꼭대기 위 2.75° 여유 |
| **B** | 수목 전체(밑동 0.03°~꼭대기 48.7°)를 프레임 세로 중앙에 | 24.37° | **+22.1** | −3.1°~51.9° | 수목 전체 span 48.7° < 55° 이므로 밑동·꼭대기 동시 수용. **A′와 사실상 같은 값** |
| C | 수관 중심을 화면 중앙에 | 43.02° | +40.8 | 15.5°~70.5° | 밑동·지면·길이 프레임 밖 → L1~L3(근경 길/중경 초원) 측정이 깨진다. 비추천 |

- L1·L2·L3 는 vista-mid 캡처의 **8밴드**(근경 밴드 6+7, 원경 밴드 2)로 잰다. pitch 를 올리면 밴드 구성이 바뀌므로(근경 길이 프레임 하단에서 줄어듦) **B 채택 시 L1~L3 재측정 필수** — 채택값은 `l1-l5-decision.json` 재판정 대상.
- 프레임 상단 여유는 세로 720 px 기준 1° ≈ 13 px. B 에서 꼭대기 위 여유 3.2° ≈ 42 px.
- 하늘이 프레임의 더 많은 비율을 차지하므로 L3 far 휘도(하늘 130~145)는 그대로이나 L5 전역 채도 중앙값은 하늘 쪽으로 내려간다(유리).

## 4. 검증 방법(GPU 세션에서)

`?shot=vista-mid` 캡처 ↔ `?shot=vista-mid&hideHero=1` 차분 bbox 의 `top` 이 0 이 아니고(꼭대기 안), `touchesTopEdge=false` 이면 채택값 확정. 이후 `measure.mjs` 로 L1~L3 재측정.
