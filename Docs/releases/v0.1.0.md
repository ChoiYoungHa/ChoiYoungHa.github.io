## M3 룩 결과

M3 룩 판정은 **L1~L5 5/5 PASS**다. 자동 명제는 S1=`vista-mid`와 S2=`vista-start`의 지정값을 사용하고, L4는 흑백 실루엣 수동 판정을 사용했다.

| 명제 | 채택값 | 판정 |
|---|---|---|
| L1 깊이별 채도 | S1 near 32.4%, far 11.4% | PASS |
| L2 온난→한랭 hue | S1 near 49.7°, far 212.2° | PASS |
| L3 원경이 밝음 | S1 near 67.3, far 134.1 | PASS |
| L4 랜드마크 실루엣 | 줄기/하늘 Δ37.2, 수관/하늘 Δ42.4; 흑백 수동 | PASS |
| L5 전역 채도 | S2 20.5% ≤ 22% | PASS |

파일 순서 1·2·3의 자동 판정은 before `1/4·2/4·1/4`에서 after `1/4·4/4·3/4`로 개선됐다. 채택값은 NeutralToneMapping, exposure `0.44`, `hueStrength=0.97`, `lumaGain=0.34`, `satFar=0.25`, `hazeMix=0.4`이며, 근거는 [`l1-l5-decision.json`](../lookdev/l1-l5-decision.json)과 [`m3-tonemap.md`](../lookdev/m3-tonemap.md)다.

### M3 잔여 관찰·미확정

- S3(`vista-village`) 원경/하늘 luma는 **166.4 > 목표 상한 145**다. 최종 L3는 지정 샷 S1의 134.1로 PASS했으므로 이 값은 샷별 잔여 편차다.
- L4의 세 번째 보조 체크인 줄기/수관 휘도차는 **5.1<10**(자체 추정 문턱 8에도 미달)이며, 수관/줄기 폭 비율 7.15의 형태 구분으로 수동 PASS했다. master 재검토 가능한 정성 판정이다.
- programs는 모든 M3-GATE run에서 **40/40(측정/예산)**으로 여유가 없다. 사전 단발 1% low 19.9fps는 동일 조건 3회에서 재현되지 않았지만, WebGL2 하위 1% 범위가 23.33~40.26으로 커서 계속 감시한다.

### 룩 변형 채택·불채택

- **채택:** grassLite는 자동 PASS **8/12**를 baseline과 동일하게 유지했고 자동 지표 최대 Δ는 **0.1**(S3 L5 15.1→15.2)이었다. 기본 on, `?grassLite=0` 강제 off다.
- **불채택·기본 off:** hazeDir는 7/12·S3 far 155.1>145, heroContrast는 L4 Δ1.8<10, vistaPitch는 5/12·bbox top 0, combo는 7/12·S3 155.1>145·L4 Δ1.8<10이었다.
- rockLite는 grassLite만으로 base 704,834≤1.1M이어서 불필요하므로 기본 off다. 근거는 [`variants-result.md`](../lookdev/variants/variants-result.md), 채택 후 [`variants-result.md`](../lookdev/variants-adopted/variants-result.md), [`base-tris-decision.md`](../decisions/base-tris-decision.md)다.
